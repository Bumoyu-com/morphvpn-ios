================================================================================
                        开始使用 - Mac 用户
================================================================================

✅ 问题已修复：iOS 部署目标版本已调整为 13.0

================================================================================
                        立即执行
================================================================================

在项目根目录运行：

    bash INSTALL_PLUGIN.sh

预期输出：
    ✅ 安装完成！
    Found 3 Capacitor plugins for ios:
      @morphvpn/capacitor-wireguard@1.0.0  ← 看到这个就成功了！

================================================================================
                        下一步
================================================================================

1. 打开 Xcode：
   npx cap open ios

2. 在 Xcode 中：
   - 连接 iOS 设备（必须是真实设备，不能用模拟器）
   - 选择设备
   - 点击运行 (⌘R)

3. 验证：
   - 应用启动后，登录页面底部显示 "平台: ios"
   - Xcode 控制台显示 "✅ WireGuardPlugin: Plugin loaded successfully"

================================================================================
                        故障排查
================================================================================

如果遇到 CocoaPods 错误：
    cd ios/App
    pod install
    cd ../..
    npx cap sync ios

如果插件未识别：
    rm -rf node_modules/@morphvpn
    bash INSTALL_PLUGIN.sh
