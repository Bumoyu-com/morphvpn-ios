================================================================================
                        给 Mac 用户的说明
================================================================================

你遇到的错误：
  npm error ENOENT: no such file or directory
  
原因：
  tarball 文件不存在，需要重新构建插件

解决方案：
  运行安装脚本

================================================================================
                        立即执行
================================================================================

在项目根目录（morphvpn-ios）运行：

  bash INSTALL_PLUGIN.sh

这会自动：
  1. 构建插件
  2. 打包插件
  3. 安装到项目
  4. 同步到 iOS
  5. 验证安装

预期输出：
  ✅ 安装完成！
  Found 3 Capacitor plugins for ios:
    @morphvpn/capacitor-wireguard@1.0.0  ← 看到这个就成功了！

================================================================================
                        下一步
================================================================================

1. 验证安装：
   npx cap ls
   
   应该看到 3 个插件（包括 @morphvpn/capacitor-wireguard）

2. 打开 Xcode：
   npx cap open ios

3. 在 Xcode 中：
   - 连接 iOS 设备（必须是真实设备）
   - 选择设备
   - 点击运行 (⌘R)

4. 查看结果：
   - 应用启动后进入登录页面
   - 底部显示 "平台: ios"
   - Xcode 控制台显示 "✅ WireGuardPlugin: Plugin loaded successfully"

================================================================================
                        如果遇到问题
================================================================================

问题 1: 脚本执行失败
  解决：查看错误信息，可能需要先安装依赖
        cd packages/wireguard-plugin
        npm install
        cd ../..
        bash INSTALL_PLUGIN.sh

问题 2: 插件仍未识别
  解决：rm -rf node_modules/@morphvpn
        bash INSTALL_PLUGIN.sh

问题 3: Xcode 编译错误
  解决：在 Xcode 中 Product → Clean Build Folder (⇧⌘K)
        然后重新运行
