================================================================================
                    插件功能
================================================================================

核心功能:
✅ 11种混淆函数
✅ 动态函数选择 (990种组合/3层)
✅ 3种协议模板 (QUIC/KCP/Gaming)
✅ UDP 连接管理
✅ 加密/解密 (AES-GCM)
✅ 混淆/解混淆
✅ 协议封装/解封装

配置参数:
- host: 服务器地址
- port: 服务器端口
- encryptionKey: 加密密钥 (base64key:base64iv)
- obfuscationLayer: 混淆层数 (1-4)
- paddingLength: 填充长度 (1-16)
- templateType: 协议模板 (0=None, 1=QUIC, 2=KCP, 3=Gaming)

================================================================================
                    快速开始
================================================================================

1. 安装插件:
   cd packages/morphprotocol-plugin && npm install && npm run build && cd ../..
   npm install ./packages/morphprotocol-plugin
   npx cap sync ios

2. 在 React 中使用:
   import { MorphProtocol } from '@morphvpn/capacitor-morphprotocol';
   
   await MorphProtocol.connect({
     host: 'your-server.com',
     port: 51821,
     encryptionKey: 'key:iv',
     obfuscationLayer: 3,
     paddingLength: 8,
     templateType: 1
   });

3. 监听事件:
   MorphProtocol.addListener('statusChanged', (data) => {
     console.log('Status:', data.status);
   });
   
   MorphProtocol.addListener('dataReceived', (data) => {
     console.log('Data:', atob(data.data));
   });

4. 发送数据:
   await MorphProtocol.send({
     data: btoa('Hello, MorphProtocol!')
   });

================================================================================
                    与 WireGuard 的关系
================================================================================

之前:
  WireGuard 插件 + MorphProtocol (耦合)
  ├── WireGuard VPN 功能
  └── MorphProtocol 混淆功能

现在:
  WireGuard 插件 (纯净)
  └── WireGuard VPN 功能
  
  MorphProtocol 插件 (独立)
  └── UDP + 加密 + 混淆 + 协议伪装

优点:
  ✅ 职责分离
  ✅ 独立测试
  ✅ 独立维护
  ✅ 可复用

================================================================================
                    测试示例
================================================================================

React 组件示例:

import { MorphProtocol } from '@morphvpn/capacitor-morphprotocol';

const TestMorphProtocol = () => {
  const [status, setStatus] = useState('disconnected');
  
  const handleConnect = async () => {
    await MorphProtocol.connect({
      host: 'server.com',
      port: 51821,
      encryptionKey: 'key:iv',
      obfuscationLayer: 3,
      paddingLength: 8,
      templateType: 1  // QUIC
    });
  };
  
  useEffect(() => {
    MorphProtocol.addListener('statusChanged', (data) => {
      setStatus(data.status);
    });
  }, []);
  
  return (
    <div>
      <p>Status: {status}</p>
      <button onClick={handleConnect}>Connect</button>
    </div>
  );
};
