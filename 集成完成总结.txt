================================================================================
                    使用方法
================================================================================

WireGuard (纯净):
  import { WireGuard } from '@morphvpn/capacitor-wireguard';
  
  await WireGuard.connect({
    config: wireguardConfig,
    tunnelName: 'MyVPN'
  });

MorphProtocol (独立):
  import { MorphProtocol } from '@morphvpn/capacitor-morphprotocol';
  
  await MorphProtocol.connect({
    host: 'server.com',
    port: 51821,
    encryptionKey: 'key:iv',
    obfuscationLayer: 3,
    paddingLength: 8,
    templateType: 1
  });
