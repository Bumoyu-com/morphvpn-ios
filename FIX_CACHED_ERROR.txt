================================================================================
                    修复缓存错误 - 快速指南
================================================================================

错误：Fetching from https://git.zx2c4.com/wireguard-apple (cached)
     Invalid manifest

原因：Xcode 使用了旧的缓存，即使配置了 Git 重定向

================================================================================
                    立即执行
================================================================================

bash clean_xcode_cache.sh

这会：
  1. 关闭 Xcode
  2. 清理所有缓存
  3. 配置 Git 重定向
  4. 验证配置

预期输出：
  ✅ Derived Data 已清理
  ✅ Swift Package 缓存已清理
  ✅ Xcode 缓存已清理
  ✅ Git 重定向已配置
  ✅ 清理完成！

================================================================================
                    然后在 Xcode 中
================================================================================

1. 打开 Xcode:
   npx cap open ios

2. 重置 Package 缓存:
   File → Packages → Reset Package Caches

3. 移除现有 Package (如果有):
   右键 wireguard-apple → Remove Package

4. 重新添加 Package:
   项目 → Package Dependencies → "+"
   URL: https://github.com/WireGuard/wireguard-apple
   Version: Up to Next Major Version (1.0.0)
   Target: WireGuardExtension 和 App

5. 验证:
   应该显示 "Fetching from https://github.com/WireGuard/wireguard-apple"
   不应该显示 git.zx2c4.com

================================================================================
                    如果仍然失败
================================================================================

使用本地克隆:
  cd ~/Downloads
  git clone https://github.com/WireGuard/wireguard-apple.git

在 Xcode 中:
  File → Add Package Dependencies → Add Local...
  选择 ~/Downloads/wireguard-apple
